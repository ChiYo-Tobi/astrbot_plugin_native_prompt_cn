# AstrBot 原生提示词定制

不限制 AstrBot 版本号。兼容性以已审阅的 4.29.4 源码为基线，逐个组装函数对比 AST 结构和运行时实现。函数挪行或只改空白、注释，不影响识别；实现有变化的函数跳过并记录日志，检查通过的函数继续替换。其他版本可能只覆盖部分文案，甚至没有可匹配的组装点。停用后恢复原生实现。

## 安装与配置

在 WebUI 安装此 ZIP，确认日志出现「原生提示词定制已挂载」。建议先停用旧「出厂提示词覆盖」，否则旧插件的英文匹配或自定义追加逻辑可能与预期不同。

每项可以独立编辑；留空恢复中文默认值，填写 `@original` 保留该项原文。占位符须照 WebUI 提示保留，漏填或拼错时该项回退原文。配置修改后重载插件，查看启动日志。

## 覆盖范围

- 主聊天：完整/渐进工具说明、工作区路径及附加文件包装、人设标题、技能目录规则、沙盒与本地环境、安全模式、本地网络限制、网页引用、实时对话、ChatUI 预览与内置默认人设。
- 其他原生入口：ChatUI 标题生成、定时任务唤醒、后台任务完成唤醒，以及 SDK 工具循环由 AstrBot 自行追加的本地网络提示。
- 只在 AstrBot 原本会产生某段文字时替换；不更改工具、权限或触发条件，不改用户自定义人设正文、路由文案、工作区附加文件正文、其他插件注入或历史消息。不处理位于 user 消息中的时间与群名提醒，也不覆盖独立子系统或第三方提供商自身的专用请求模板。

本插件使用按组装函数校验的进程内补丁，不是 AstrBot 官方稳定扩展 API。新增兼容实现前，须重新审阅相关组装逻辑，不能只重算指纹。

## Python 版本

指纹按 `ast.dump` 结果计算，而 Python 3.13 起 `ast.dump` 新增 `show_empty` 参数且默认 `False`，会省略空字段，导致同一份源码在 3.13+ 上算出与 3.12 不同的哈希，所有组装点都会被判为「已变更」。插件现已显式传入 `show_empty=True`（旧解释器无此参数时自动回退），因此 3.12 与 3.13+ 使用同一套指纹。
